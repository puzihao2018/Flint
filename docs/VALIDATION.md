- 4.0.12 与 4.1.2 独立环境和配置，4.0 Jobs API 上传与 ZIP 结果验证。

## 仓库测试

`npm test` 使用临时数据根和本机回环端口，测试配置、端口冲突、连续启动、停止、进程组清理、崩溃、健康检查失败、中断记录、JSON/SSE MCP 初始化、安装取消和清单解析。串行运行，避免测试之间争用临时端口；其他系统进程仍可能抢占释放后的端口。

`npm run release:mac` 检查版本、固定 uv 校验、应用身份/架构、第三方声明和代码签名，生成并校验 DMG。CI 不下载模型或遍历用户文献库。真实 MinerU 验证脚本只读取显式传入的测试文件；headless 验证器必须使用独立数据目录。

## 未完成的验证

Intel、Windows、Linux、全部 macOS 版本/芯片、所有 MinerU 档位与模型源、Developer ID 公证，以及真实 GitHub Actions 托管执行。不要将构建成功当成这些场景已经验收。
