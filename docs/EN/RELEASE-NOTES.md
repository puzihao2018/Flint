# Flint 0.1.13 · macOS alpha

[简体中文](https://github.com/puzihao2018/Flint/blob/v0.1.13/docs/CN/RELEASE-NOTES.md)

Fixed the alignment of service icons in the menu bar panel, including the MinerU “M”.

Open the DMG and drag Flint into Applications. If upgrading, stop active services and quit Flint first. The ZIP contains the same app. Checksums are in SHA256SUMS.txt. This build requires macOS 13 or later on Apple Silicon and uses an ad-hoc signature. It has not been notarized by Apple.
